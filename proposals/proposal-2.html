That is the problem Sentinel8004 solves. Every agent gets a composite score across five independent layers, with circuit breakers that cap scores when spam patterns are detected.

03 / Pipeline

Six steps from registry read to on-chain attestation. Fully autonomous, no human in the loop.

1
Enumerate
Read every token from the IdentityRegistry ERC-721 contract. Parse metadata from five formats: gzip, base64, IPFS, HTTP, and raw JSON.
2
Probe
Hit every declared endpoint with HTTP probes. Measure response times, status codes, and content types. Dead endpoints trigger circuit breakers.
3
Score (5 Layers)
Registration quality, endpoint liveness, on-chain wallet behavior via Blockscout, Sybil/spam detection, and existing reputation feedback. Each layer scores independently.
4
Circuit Breakers
Hard caps for known-bad patterns. Mass registration from a single wallet caps at 15. Cloned metadata caps at 25. Scores cannot be inflated past circuit breaker ceilings.
5
Composite
Weighted sum across all layers produces a final 0-100 score with a confidence level (high, medium, low) based on how many layers contributed data.
6
Write On-Chain
Pin the full report to IPFS. Write the score, confidence hash, and IPFS URI to the ReputationRegistry contract on Celo. Every score is verifiable.

04 / Integration

Any agent or contract on Celo can read trust scores directly from the ReputationRegistry.

Read trust scores on-chain 
// Any agent or contract can query trust scores
const feedback = await registry.getFeedback(agentId);
// => { value: 95n, tag1: "sentinel8004", feedbackURI: "ipfs://..." }

// Gate untrusted agents before interaction
if (feedback.value < 30n) {
  throw new Error("Agent untrusted — score below threshold");
}

// Verify the full report via IPFS
const report = await fetch(feedback.feedbackURI);
const { compositeScore, layers, circuitBreakers } = await report.json();
Direct Contract
